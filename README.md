# 미로 탈출

안개 속에서 길을 찾는 미로 탈출 게임. 설치 없이 브라우저에서 바로 플레이합니다.

▶ **플레이**: https://skygaul.github.io/my-maze-game/

## 조작
- 방향키 / WASD: 누르고 있으면 부드럽게 이동
- R: 다시 시작 · N: 새 미로 · F: 안개 모드 켜기/끄기

## 특징
- 매번 새로 생성되는 랜덤 미로 (쉬움 10×10, 보통 16×16, 어려움 24×24)
- 안개 모드: 주변 몇 칸만 보이는 시야
- 난이도/안개 여부별 최고 기록 저장 (브라우저 localStorage)

순수 HTML/CSS/JavaScript로 만들었습니다.
